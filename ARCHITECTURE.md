# Architecture Danîa✨ V1

- `lib/main.dart` : navigation principale et accueil
- `lib/theme.dart` : identité visuelle Danîa✨
- `lib/screens/editor_screen.dart` : éditeur, filtres, texte, cadres, export
- `lib/services/gallery_service.dart` : sauvegarde galerie
- `lib/services/wallpaper_service.dart` : application du fond Android
- `assets/images/dania_logo.png` : logo fourni pour Danîa✨

La V1 est volontairement locale : aucune base de données ni compte utilisateur n'est requis pour tester l'éditeur.
